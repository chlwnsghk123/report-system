# 📝 학습 리포트 생성기

순수 프론트엔드 학습 리포트 도구입니다. CDN 전용(빌드도구·npm 없음), 데이터는 IndexedDB에 자동 저장됩니다.

---

## 🚀 사용 방법

1. `start.bat` 실행 후 `http://localhost:8000` 에서 열기 (또는 로컬 HTTP 서버 사용)
2. **📂 엑셀 파일 불러오기** 클릭 → `.xlsx` 파일 선택
3. **⚙ 수업설정** 뷰에서 수업 날짜·교재·과제 편집 (또는 학생 추가/삭제)
4. 상단 **날짜 탭**에서 수업일 선택 → 날짜 뷰로 전환
5. **학생 탭**에서 학생 선택
6. 이전 과제 이행 상태 입력 (완료/부분완료/미완료 순환 버튼)
7. 필요 시 **미니 테스트** / **코멘트** 토글 활성화
8. **📄 PDF로 저장** 버튼 클릭

## 📊 엑셀 파일 구조 (신규 포맷)

### 시트 1 — 수업정보
| 열 | 내용 |
|----|------|
| 날짜 | YYYY-MM-DD 형식 (예: 2026-03-03) |
| 교재 | 교재명 |
| 단원 | 단원명 |
| 상세진도 | 상세 진도 내용 |
| 과제1~N | 이번 주 과제 항목 (동적 개수) |

### 시트 2+ — 날짜별 시트 (예: "2026-03-09")
| 열 | 내용 |
|----|------|
| 이름 | 학생 이름 |
| 성적 | "맞힌수/전체수" 형식 (예: "5/5") |
| 오답 | 쉼표 구분 오답 번호 |
| 과제이행률 | 0~100 (%) |
| 과제1~N | 상태값 (0=미완료, 1=부분완료, 2=완료, 동적 개수) |
| 비고 | 이월과제 요약 (자동 생성, 로드 시 무시) |

### 이월과제 시트
| 열 | 내용 |
|----|------|
| 학생 | 학생 이름 (또는 `▼ 날짜` 구분행) |
| 확인날짜 | 과제 체크 수업 날짜 |
| 과제내용 | 과제 텍스트 |
| 원본날짜 | 처음 출제된 수업 날짜 |
| 상태 | 0=미완료, 1=부분완료, 2=완료 |

### 하위 호환 (구 포맷)
- 수업정보에 강사명·전체문제수 열 포함, 별도 성적 시트, 학생명 시트 구조
- `parseWB()` 에서 시트명 기반 자동 감지

## ✅ 주요 기능

- **수업설정 모달** — 전체화면 모달에서 수업 날짜·교재·단원·과제 편집, 과제 동적 추가/삭제, 과거 날짜 회색·다음 수업 파란 강조
- **학생 관리** — 학생 추가/삭제, 탭 전환으로 독립 입력
- **이전 과제 이행** — 완료/부분완료/미완료 순환 버튼, 자동 이행률 계산
- **과제 캐리오버** — 미완료/부분완료 과제 자동 이월, "(전)" 뱃지 표시, 이번 주차 과제에 미완료 항목 자동 반영
- **이행률 그래프** — 최근 4회 이행률 SVG 꺾은선 그래프
- **미니 테스트** (토글) — 맞힌 수/전체 문제, 점수 자동 계산 (20 + ceil(정답/전체 × 30)), 오답 태그
- **코멘트** (토글) — 선생님 한 줄 코멘트 + 서명
- **PDF 저장** — 가로 A4에 리포트 + 시험자료 PDF 나란히 합성 (pdf-lib + html2canvas)
- **시험자료 첨부** — PDF 파일 첨부 후 스프레드 뷰로 미리보기
- **엑셀 저장** — 현재 데이터를 엑셀 파일로 다운로드
- **템플릿 생성** — 빈 엑셀 템플릿 자동 생성 (오늘~6월, 주 1회)
- **자동 저장** — IndexedDB에 자동 저장 (DB: `reportApp4`, STORE: `data`)
- **자동채우기** — 날짜·학생 선택 시 교재/과제/점수 등 자동 입력
- **반응형** — 1024px 이하에서 세로 레이아웃 전환

## 💡 팁

- 수업일 추가: ⚙ 수업설정 뷰 하단의 **+ 수업 추가** 버튼 사용
- 학생 추가: ⚙ 수업설정 뷰 상단의 학생 관리 섹션 사용
- 날짜 탭은 좌우 화살표(◀▶)로 스크롤 가능
- 과제 이행 버튼: 없음 → ✓완료 → △부분완료 → ✗미완료 → 없음 순환
- PDF 저장 전 **💾 파일 저장**을 먼저 권장
- 구 포맷(강사명·성적시트 구조) 엑셀 파일도 자동 인식됨
