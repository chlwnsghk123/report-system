# 📝 학습 리포트 생성기

순수 프론트엔드 학습 리포트 도구입니다. CDN 전용(빌드도구·npm 없음), 데이터는 **엑셀 파일**에 저장하고 브라우저(IndexedDB)에 자동 백업됩니다.

---

## 🚀 사용 방법

1. `start.bat` 실행 후 `http://localhost:8000` 에서 열기 (또는 로컬 HTTP 서버 사용)
2. **📂 엑셀 파일 불러오기** 클릭 → `.xlsx` 파일 선택
3. **⚙ 수업설정** 뷰에서 수업 날짜·교재·과제 편집 (또는 학생 추가/삭제)
4. 상단 **날짜 탭**에서 수업일 선택 → 날짜 뷰로 전환
5. **학생 탭**에서 학생 선택
6. 이전 과제 이행 상태 입력 (완료/부분완료/미완료 순환 버튼)
7. 필요 시 **미니 테스트** / **선생님 한마디** 토글 활성화
8. **📄 PDF로 저장** 버튼 클릭

## 📊 엑셀 파일 구조 (신규 포맷)

### 시트 1 — 수업정보
| 열 | 내용 |
|----|------|
| 날짜 | YYYY-MM-DD 형식 (예: 2026-03-03) |
| 교재 | 교재명 |
| 단원 | 단원명 |
| 상세진도 | 상세 진도 내용 |
| 과제1~N | 이번 주 과제 항목 (동적 개수) |

### 시트 2+ — 날짜별 시트 (예: "2026-03-09")
| 열 | 내용 |
|----|------|
| 이름 | 학생 이름 |
| 성적 | "맞힌수/전체수" 형식 (예: "5/5") |
| 오답 | 쉼표 구분 오답 번호 |
| 과제이행률 | 0~100 (%) |
| 과제1~N | 상태값 (0=미완료, 1=부분완료, 2=완료, 동적 개수) |
| 비고 | 이월과제 요약 (자동 생성, 로드 시 무시) |

### 이월과제 시트
| 열 | 내용 |
|----|------|
| 학생 | 학생 이름 (또는 `▼ 날짜` 구분행) |
| 확인날짜 | 과제 체크 수업 날짜 |
| 과제내용 | 과제 텍스트 |
| 원본날짜 | 처음 출제된 수업 날짜 |
| 상태 | 0=미완료, 1=부분완료, 2=완료 |

### 하위 호환 (구 포맷)
- 수업정보에 강사명·전체문제수 열 포함, 별도 성적 시트, 학생명 시트 구조
- `parseWB()` 에서 시트명 기반 자동 감지

## ✅ 주요 기능

- **수업설정 모달** — 전체화면 모달에서 수업 날짜·교재·단원·과제 편집, 과제 동적 추가/삭제 (날짜를 바꾸면 그 날짜의 기록도 함께 이동)
- **학생 관리** — 학생 추가/삭제/이름 변경(기록 유지), 사이드바·키보드(↑↓)로 전환
- **출결** — 출석/지각/결석 토글(다시 누르면 해제), **전원 출석** 한 번에
- **지난 수업 과제 검사** — 완료/부분완료/미완료 순환 버튼, **모두 완료**, 이행률 **자동 계산**(직접 입력도 가능)
- **과제 캐리오버** — 미완료/부분완료 과제 자동 이월, "(이월)" 표시, 다음 수업 과제에 자동 반영, 과제별 ON/OFF
- **이행률 그래프** — 최근 4회 꺾은선 그래프 (결석은 회색 '결석')
- **미니 테스트** (토글) — 문항 수·범위·오답 번호 → 점수(3/5)·'다시 볼 문제' 표시, 기록 없는 학생은 자동 숨김
- **선생님 한마디** (토글) — 학생별 코멘트 + 서명, 수업 일지표 코멘트와 공유
- **PDF 저장** — 첨부 없으면 세로 A4 1장, 시험자료 첨부 시 가로 A4에 나란히 (pdf-lib + html2canvas)
- **카톡용 이미지** — 리포트를 폭 1080px JPG로 저장, 반 전체를 학생별 이미지 ZIP으로
- **수업 일지표** — 원장님 보고용 PDF (출결·이행률표·숙제 검사·오답 집계·코멘트·다음 계획)
- **이행률 요약표** — 학생별(상담용) / 전체
- **엑셀 저장** — 현재 데이터를 엑셀 파일로 다운로드 (Ctrl+S)
- **자동 백업·복구** — 편집할 때마다 IndexedDB에 백업, 다음 실행 때 '지난 작업 이어하기'
- **A4 자동 맞춤** — 내용이 많으면 간격을 줄이고 목록을 2단으로

## 💡 팁

- 수업일 추가: 날짜 네비의 **+** 버튼 또는 ⚙ 설정 → 수업 진도 설정의 **➕ 날짜 추가**
- 학생 추가: ☰ 메뉴 → 학생 관리 → 학생 추가 (쉼표로 여러 명)
- 날짜는 키보드 ←→, 학생은 ↑↓로 이동
- 과제 이행 버튼: 없음 → ✓완료 → △부분완료 → ✗미완료 → 없음 순환
- PDF 저장 전 **💾 파일 저장**을 먼저 권장
- 구 포맷(강사명·성적시트 구조) 엑셀 파일도 자동 인식됨
