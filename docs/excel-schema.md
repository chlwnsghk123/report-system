# 엑셀 파일 구조 (학습리포트_데이터.xlsx)

> 이 문서가 있으면 AI에게 .xlsx 파일을 직접 줄 필요 없음.
> 엑셀 파싱/저장 작업 시 이 파일만 참조하면 됨.

---

## 시트 목록 (신규 형식)

| 시트명 | 역할 |
|---|---|
| `수업정보` | 날짜별 수업 내용 및 과제 (동적 열) |
| `YYYY-MM-DD` _(날짜별)_ | 해당 날짜 학생 전체의 성적·과제이행 현황 + 비고 열 |
| `이월과제` | 미완료/부분완료 과제 캐리오버 추적 (▼ 날짜별 블록 구분) |

> **하위 호환:** 구 형식(강사명 포함 수업정보 + 성적 시트 + 학생별 시트)도 `parseWB`에서 읽기 지원.

---

## 시트 1: 수업정보

**헤더 행 (0행):**

| 열 인덱스 | 열 이름 | 타입 | 예시 |
|---|---|---|---|
| 0 | 날짜 | Date / 숫자코드 | `2026-03-03` 또는 엑셀 날짜코드 |
| 1 | 교재 | string | `수학의 정석` |
| 2 | 단원 | string | `2단원 함수` |
| 3 | 상세진도 | string | `p.45~52 예제풀이` |
| 4+ | 과제1~N | string | `p.53 연습문제 1~5` (동적 개수, 최소 1열) |

> **강사명 열 제거됨** (구 형식에서는 열1이 강사명이었으나, 신규 형식에서는 제거)

**정렬:** 날짜 오름차순 (`toDS()` 통해 정규화 후 sort)

## 시트 2~N: 날짜별 시트 (예: `2026-03-09`)

**행 구조:**

| 행 | 역할 |
|---|---|
| 0 | 헤더 (`이름`, `성적`, `오답`, `과제이행률`, `과제1`~`과제N`, `비고`) |
| 1+ | 학생별 데이터 |

**열 구조 (학생 데이터 행):**

| 열 인덱스 | 열 이름 | 내용 |
|---|---|---|
| 0 | 이름 | 학생 이름 |
| 1 | 성적 | `맞힌수/전체문제수` 형식 (예: `5/5`, `3/5`) |
| 2 | 오답 | 오답 번호 문자열 (예: `"2,4"`) |
| 3 | 과제이행률 | 숫자 (0~100), 로드 시 `normalizeRate()`로 정규화 |
| 4~N | 과제1~N | 과제 상태 (`2`=완료, `1`=부분완료, `0`=미완료, 공란=없음, 동적 개수) |
| N+1 | 비고 | 이월과제 자동 요약 + 사용자 메모 통합 (`자동요약 | 메모` 형식) |

### 과제 상태 매핑

| 엑셀 값 | 의미 | 내부 한글 |
|---|---|---|
| (공란) | 없음/해당없음 | `''` |
| `0` | 미완료 | `미완료` |
| `1` | 부분완료 | `부분완료` |
| `2` | 완료 | `완료` |

> **하위 호환:** 읽기 시 기호(`○`=완료, `△`=부분완료, `X`=미완료)도 지원

**예시 시트 (2026-03-09):**

```
이름    성적   오답   과제이행률   과제1   과제2   과제3   과제4
하정    5/5          100        2       1       0
김도은  5/5          80         2       2
윤희    3/5          60         2
황선재  2/5          40
원빈    1/5    2,4   20
희은    5/5          100        2       2       2       2
```

**파싱 결과:**
- `G.students[]` — 첫 번째 날짜 시트 기준으로 학생 순서 결정
- `G.corrects[학생명][날짜]` — 맞힌 개수
- `G.wrong[학생명][날짜]` — 오답 번호 문자열
- `G.rates[학생명][날짜]` — 과제이행률
- `G.hwRec["학생명||날짜"]` = `{이행률, 과제1_상태~과제N_상태, items:[{text,status,type,fromDate}]}`

## 날짜 형식 정규화 규칙 (`toDS` 함수)

```
입력: "2026/03/03"  → "2026-03-03"
입력: "2026-03-03"  → "2026-03-03"
입력: 46083 (엑셀코드) → XLSX.SSF.parse_date_code() → "2026-03-03"
규칙: replace('/', '-') 후 substring(0,10)
```

## saveToExcel 저장 구조

`G → 엑셀` 방향으로 세 가지 시트 타입으로 재생성.

1. `수업정보` 시트: G.lessons 전체 (동적 과제 열)
2. 날짜별 시트: G.lessons의 각 날짜마다 1개, G.students 전체 포함 + 비고 열 (이월과제 요약)
3. `이월과제` 시트: 캐리오버 항목 (▼ 날짜별 블록 구분)
4. 과제 상태는 숫자(`2`/`1`/`0`)로 저장, 공란은 공란 유지

기존 파일명 `G.excelFileName` 기준으로 다운로드.

## 이월과제 시트

| 열 | 내용 | 비고 |
|---|---|---|
| A | 학생 | 이름 또는 `▼ 날짜` (구분행) |
| B | 확인날짜 | 이 과제를 체크하는 수업 날짜 |
| C | 과제내용 | 과제 텍스트 |
| D | 원본날짜 | 처음 출제된 날짜 |
| E | 상태 | 2/1/0/공란 |

구분행 `▼ YYYY년 M월 D일 (요일)` → 로드 시 무시.
수동으로 행 추가 가능 (상태 비우면 앱에서 "없음"으로 처리).

## 학생 관리

- `G.students[]` 가 마스터 목록
- UI의 **수업설정 뷰 > 학생 목록** 섹션에서 추가/삭제 가능
- 저장 시 현재 `G.students` 기준으로 모든 날짜 시트 자동 재생성
- `createTemplate()` 호출 시 오늘~6월까지 주 1회 날짜 + 기본 학생 3명으로 템플릿 생성

## 구 형식 (하위 호환)

시트명이 날짜 형식(`YYYY-MM-DD`)이 아닌 파일은 구 형식으로 간주:
- `수업정보` 시트 헤더에 `강사명` 열 포함 → 열 인덱스 +1 보정하여 파싱
- `성적` 시트: 날짜별 맞힌수·오답 데이터
- 학생 이름 시트: 과제이행 기록
- 과제 상태: 기호(○/△/X) 형식도 `stFromExcel()`에서 자동 변환
