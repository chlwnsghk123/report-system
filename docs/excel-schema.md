# 엑셀 파일 구조 (학습리포트_데이터.xlsx)

> 이 문서가 있으면 AI에게 .xlsx 파일을 직접 줄 필요 없음.
> 엑셀 파싱/저장 작업 시 이 파일만 참조하면 됨.

---

## 시트 목록 (신규 형식)

| 시트명 | 역할 |
|---|---|
| `수업정보` | 날짜별 수업 내용 및 과제 (동적 열) |
| `YYYY-MM-DD` _(날짜별)_ | 해당 날짜 학생 전체의 성적·과제이행 현황 + 비고 열 |
| `이월과제` | 미완료/부분완료 과제 캐리오버 추적 (▼ 날짜별 블록 구분) |

> **하위 호환:** 구 형식(강사명 포함 수업정보 + 성적 시트 + 학생별 시트)도 `parseWB`에서 읽기 지원.

## 시트 1: 수업정보

**헤더 행 (0행):**

| 열 인덱스 | 열 이름 | 타입 | 예시 |
|---|---|---|---|
| 0 | ID | string | `4758948383` (10자리 난수, 수업 고유 식별자) |
| 1 | 날짜 | Date / 숫자코드 | `2026-03-03` 또는 엑셀 날짜코드 |
| 2 | 교재 | string | `수학의 정석` |
| 3 | 단원 | string | `2단원 함수` |
| 4 | 상세진도 | string | `p.45~52 예제풀이` |
| 5+ | 과제1~N | string | `p.53 연습문제 1~5` (동적 개수, 최소 1열) |

> **ID열**: `genLessonId()`로 생성. 읽기 시 헤더에 'ID'가 없으면 자동 생성.
> **강사명 열 제거됨** (구 형식에서는 열1이 강사명이었으나, 신규 형식에서는 제거)

**정렬:** 날짜 오름차순 (`toDS()` 통해 정규화 후 sort)

## 시트 2~N: 날짜별 시트 (예: `2026-03-09`)

**행 구조:**

| 행 | 역할 |
|---|---|
| 0 | 헤더 (`이름`, `출결`, `오답`, `과제이행률`, `과제1`~`과제N`, `비고`) |
| 1+ | 학생별 데이터 |

**열 구조 (학생 데이터 행):**

| 열 인덱스 | 열 이름 | 내용 |
|---|---|---|
| 0 | 이름 | 학생 이름 |
| 1 | 출결 | 출결 상태 (`2`=출석, `1`=지각, `0`=결석, `-1`=특수/제외, 공란=미선택). **사용자가 선택한 값 그대로 저장** — 이행률로 보정하지 않음 |
| 2 | 오답 | 오답 번호 문자열 (예: `"2,4"`) |
| 3 | 과제이행률 | 숫자 (0~100), 로드 시 `normalizeRate()`로 정규화 |
| 4~N | 과제1~N | 과제 상태 (`2`=완료, `1`=부분완료, `0`=미완료, 공란=없음, 동적 개수) |
| N+1~M | 추가과제1~M | 학생별 추가 숙제 (`내용|상태숫자` 형식, 동적 개수) |
| 마지막 | 비고 | 이월과제 자동 요약 + 사용자 메모 통합 (`자동요약 | 메모` 형식) |

### 과제 상태 매핑

| 엑셀 값 | 의미 | 내부 한글 |
|---|---|---|
| (공란) | 없음/해당없음 | `''` |
| `0` | 미완료 | `미완료` |
| `1` | 부분완료 | `부분완료` |
| `2` | 완료 | `완료` |

> **하위 호환:** 읽기 시 기호(`○`=완료, `△`=부분완료, `X`=미완료)도 지원

**예시 시트 (2026-03-09):**

```
이름    출결   오답   과제이행률   과제1   과제2   과제3   과제4   비고
유하정  2            100        2       1       0
김도은  2            80         2       2                       [이월] ...
서윤희  2            60         2
황선재  2            40
인원빈  2      2,4   20
김희은  2            100        2       2       2       2
```

**파싱 결과:**
- `G.students[]` — 첫 번째 날짜 시트 기준으로 학생 순서 결정
- `G.corrects[학생명][날짜]` — 맞힌 개수
- `G.wrong[학생명][날짜]` — 오답 번호 문자열
- `G.rates[학생명][날짜]` — 과제이행률
- `G.hwRec["학생명||날짜"]` = `{이행률, 과제1_상태~과제N_상태, items:[{text,status,type,fromDate}]}`

## 날짜 형식 정규화 규칙 (`toDS` 함수)

```
입력: "2026/03/03"  → "2026-03-03"
입력: "2026-03-03"  → "2026-03-03"
입력: 46083 (엑셀코드) → XLSX.SSF.parse_date_code() → "2026-03-03"
규칙: replace('/', '-') 후 substring(0,10)
```

## saveToExcel 저장 구조

`G → 엑셀` 방향으로 세 가지 시트 타입으로 재생성.

1. `수업정보` 시트: ID열 + G.lessons 전체 (동적 과제 열)
2. 날짜별 시트: G.lessons의 각 날짜마다 1개, G.students 전체 포함 + 추가과제 + 비고 열 (이월과제 요약)
3. `이월과제` 시트: 캐리오버 항목 (▼ 날짜별 블록 구분)
4. `설정` 시트: 스티커 + 이번 주차 과제 OFF 상태 + 마지막 저장 시각
5. 과제 상태는 숫자(`2`/`1`/`0`)로 저장, 공란은 공란 유지

기존 파일명 `G.excelFileName` 기준으로 다운로드.

## 이월과제 시트 (신형식 — 참조 기반)

> **언제 만들어지나**: 멀티홉 캐리오버(2단계 이상 건너뛴 미완료 과제)가 있을 때만 시트가 생성됨.
> 직전 회차의 미완료는 다음 회차의 과제N 컬럼에 이미 저장되므로 별도 시트가 필요 없음.
> 한 학생의 미완료가 두 회차 이상 추적되어야 할 때 비로소 이월과제 시트에 기록됨.

| 열 | 내용 | 비고 |
|---|---|---|
| A | 학생 | 이름 또는 `▼ 날짜` (구분행) |
| B | 확인날짜 | 이 과제를 체크하는 수업 날짜 |
| C | 참조 | base 과제: `{수업ID}-과제{N}` / 추가과제: `{수업ID}@x@{텍스트}` (텍스트 기반) |
| D | 상태 | 2/1/0/공란 |

### Ref 형식 (v1.68+)

- **base 과제**: `1234567890-과제1` — 수업ID + `-` + `과제N` 키
- **추가과제 (신 형식)**: `1234567890@x@심화문제집` — 수업ID + `@x@` + 텍스트
  - 텍스트가 ref에 박혀 있으므로 인덱스 흔들림 문제(추가과제 삭제·재정렬) 없음
  - 같은 학생 한 회차에 동일 텍스트 추가과제는 자동으로 무시(silent dedupe)
- **추가과제 (구 형식)**: `1234567890-추가과제1` — 마이그레이션 대상
  - 로드 시 자동으로 신 형식으로 변환됨 (`parseWB`의 이월과제 시트 파싱 단계)

### 파싱 헬퍼

`parseHwRef(ref)` (utils.js)이 신/구 형식을 모두 처리. 모든 ref 사용처는 이 헬퍼를 호출함:
- `_resolveCarryRef` (autofill.js), `_resolveRefText` (excel.js)
- `refToCheckDate` (utils.js), `_getOriginalRefStatus` (ui.js)

구분행 `▼ YYYY년 M월 D일 (요일)` → 로드 시 무시.
수동으로 행 추가 가능 (상태 비우면 앱에서 "없음"으로 처리).

> **하위 호환:** 구형식(과제내용 열 포함 5열)도 헤더 기반으로 자동 감지하여 파싱.

## 설정 시트

잡다한 앱 설정을 저장하는 시트. 없으면 새로 생성, 있으면 읽기/저장.
`▼ 섹션명` 구분행으로 카테고리 구분.

헤더 행: `키`, `값1`, `값2`

| 섹션 | 열 | 내용 |
|---|---|---|
| `▼ 스티커` | A: 학생명, B: tier(high/mid/low), C: 인덱스 | 학생별·점수대별 마스코트 선택 (학생당 최대 3행) |
| `▼ 과제OFF` | A: `학생||날짜`, B: 과제 ref | 이번 주차 과제 ON/OFF 중 **OFF**된 항목 (`G.hwDisabled`). OFF 과제는 다음 주차 체크목록에서도 제외 |
| `▼ 마지막저장` | A: `lastSaved`, B: 날짜시간 문자열 | 마지막 엑셀 저장 시각 (`YYYY-MM-DD HH:MM:SS`, KST) |

## 학생 관리

- `G.students[]` 가 마스터 목록
- UI의 **수업설정 뷰 > 학생 목록** 섹션에서 추가/삭제 가능
- 저장 시 현재 `G.students` 기준으로 모든 날짜 시트 자동 재생성
- `createTemplate()` 호출 시 오늘~6월까지 주 1회 날짜 + 기본 학생 3명으로 템플릿 생성

## 구 형식 (하위 호환)

시트명이 날짜 형식(`YYYY-MM-DD`)이 아닌 파일은 구 형식으로 간주:
- `수업정보` 시트 헤더에 `강사명` 열 포함 → 열 인덱스 +1 보정하여 파싱
- `성적` 시트: 날짜별 맞힌수·오답 데이터
- 학생 이름 시트: 과제이행 기록
- 과제 상태: 기호(○/△/X) 형식도 `stFromExcel()`에서 자동 변환
